# Sistema-Atencion-de-Turnos
Aplicación para administrar atención de clientes en una oficina de servicios. El sistema registra: clientes, gestionar servicios, generar turnos y atenderlos en orden de llegada. El proyecto integrará programación orientada a objetos, colecciones, listas enlazadas, colas, árboles binarios de búsqueda y persistencia en una base de datos (SQLite).
